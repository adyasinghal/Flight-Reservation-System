# Flight-Reservation-System

This project is a simple, menu-driven console application developed in C to simulate a foundational Flight Reservation System. It allows users to manage flight bookings, passenger details, and seat availability in real-time.  

It was developed as a submission for the CDS101 (Introduction to Computing and Programming) course project.  

## Features

The application provides the following core functionalities through a command-line interface:  

1. Book Flight: Allows users to book one or more seats on an available flight and stores passenger information (Name, Age, Phone).

2. Cancel Booking: Handles the cancellation of booked seats by passenger name, restoring available seats to the flight.

3. Update Passenger Info: Enables modification of existing passenger details (Name, Age, Phone) for a specific flight.

4. View Passengers: Displays a complete list of all passengers currently registered for a given flight number.

5. Exit: Terminates the application.
